# whisper-kit

**本機語音辨識（faster-whisper）：影片/音檔 → 帶時間的逐字稿。顯卡優先、失敗退回 CPU、即時進度、斷句、中文轉台灣繁體、非預期語言防呆。Python 模組 + CLI + Node 包裝，不花錢。** 零依賴、框架無關。

## 安裝

```bash
npm i github:Jeffrey0117/whisper-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('whisper-kit');
const x = create({ /* opts */ });
```
